Bắt đầu nhanh Quản lý tài khoản Bán hàng & CRM Kế toán API cho Developers

1. Hướng dẫn cài đặt hệ thống

Chào mừng bạn đến với ERPVIET. Để bắt đầu sử dụng, bạn cần thiết lập tài khoản quản trị viên và cấu hình thông tin doanh nghiệp cơ bản.

Lưu ý: Bạn cần có quyền Admin để thực hiện các thao tác này.

Bước 1: Đăng ký tài khoản

Truy cập trang đăng ký và điền thông tin doanh nghiệp. Sau khi đăng ký thành công, hệ thống sẽ gửi email xác nhận.

Bước 2: Cấu hình thông tin công ty

Vào mục Cài đặt > Thông tin chung để cập nhật Logo, Mã số thuế và Địa chỉ.

2. Kết nối API (Dành cho lập trình viên)

ERPVIET cung cấp RESTful API để bạn tích hợp với các hệ thống bên thứ 3.

// Ví dụ gọi API lấy danh sách sản phẩm
GET https://api.erpviet.vn/v1/products
Authorization: Bearer YOUR_TOKEN_HERE

Xem chi tiết tài liệu API đầy đủ tại Developer Hub.
